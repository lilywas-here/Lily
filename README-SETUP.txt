# Lilian DeLeo Portfolio

## Files
- `index.html` — portfolio homepage
- `style.css` — responsive editorial styling
- `images/headshot.jpg` — add your headshot here
- `Lilian_DeLeo_Resume_2026.pdf` — existing resume PDF; keep this exact filename

## Publish with GitHub Pages
Upload `index.html` and `style.css` to the repository root. Keep your existing `CNAME` and resume PDF. Create an `images` folder and upload your portrait as `headshot.jpg`.

The HTML links to the PDF using its current filename. If your PDF has a different filename, update the three references in `index.html`.

The site is designed to work at the root of a custom domain such as https://lilydeleo.com/.
