# Lilian DeLeo Portfolio

## Files
- `index.html` — portfolio homepage
- `style.css` — responsive editorial styling
- `images/headshot.jpg` — add your headshot here
- `Lilian_DeLeo_Resume_2026.pdf` — keep your existing resume PDF with this exact filename

## Publish with GitHub Pages
Upload `index.html` and `style.css` to the repository root. Keep your existing `CNAME` and resume PDF. Create an `images` folder and upload your portrait as `headshot.jpg`.

The HTML links to the PDF using its current filename. If your PDF has a different filename, update the references in `index.html`.

Before publishing, replace the contact links with your preferred email and LinkedIn URLs.
